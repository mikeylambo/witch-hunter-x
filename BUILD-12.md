# Build 0.12 — Primitive Ceiling

This is the intentional stopping point for primitive-driven development.

## Playable mission structures
1. False Saint — purge -> escalation -> three-phase Magical Girl boss.
2. Hex District — escalating ritual surges -> Coven Matriarch.
3. Black Procession — defend/move an objective through waves -> Siren Prime.

## Hunter progression represented
- Shared passive slot.
- One selectable identity mod per hunter.
- Permanent technique unlocks.
- Tactical consumables.
- X Gauge and Install states.
- Character-specific defensive mechanics.
- Character-specific controller verbs.

## Enemy content represented
- Hex, Coven, Ritual, Siren, Magical classes.
- Formation support, interrupt casts, formation pulls, projectile pressure.
- Three-phase bosses with phase transitions, adds, burst pressure, radial projectile patterns.
- Boss Break windows and positional-control immunity.

## Why stop here
Further primitive work would mostly tune abstract numbers or add more geometric proxies. The next meaningful gains require:
- real hunter models
- actual animation clips / Character Frame integration
- authored hitboxes per animation
- weapon/construct/drone meshes
- witch silhouettes and boss animation telegraphs
- environment art / authored mission spaces
- VFX hierarchy and audio feedback

The combat/progression/mission contracts are now rich enough to receive production assets.
