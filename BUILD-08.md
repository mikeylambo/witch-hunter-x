# Witch Hunter // X — Build 0.8

This build turns the four placeholder combat slots into four distinct controller philosophies.

## Universal combat rules implemented
- Positional states are mutually exclusive: Ground, Launch, Carry, Suspend, Spike, Wallsplat.
- Overlay states stack: Cut, Tether, Break.
- Positional priority: Suspend > Carry > Spike/Wallsplat > Launch > Ground.
- Damage decay during uninterrupted air control.
- Per-state control decay in a rolling five-second window.
- Boss positional-lock immunity outside Break.
- Handoff scoring requires a different hunter to continue a non-ground sequence.
- No friendly fire.

## Hunter identity pass
- Riven: Arsenal Core with four Frames, frame-specific Heavy, Switch Entry effects, Parry-Switch.
- Vale: Cut planting, Fracture/Judgment payoff, Guard Cut.
- Knox: Seize-based light/heavy control, Spike signature, Seize-Catch that currently reflects projectiles as the first upgrade proof.
- Morrow: three persistent drones, paired light, coordinated heavy, network suspend/tether, Network Guard interception.

## Controls
P1: WASD / J Light / K Heavy / L Signature / Q Defense / Space Evade
P2–4: Gamepad LS / A Light / X Heavy / Y Signature / LB Defense / B Evade

Art, animation, final weapon naming, final tech naming, narrative presentation, and audio remain intentionally provisional.
