# Witch Hunter // X — Build 0.9

## Goal
Turn the combat proof into a minimally complete mission loop before art/animation production.

## Added
- 1–4 player runtime activation: P1 keyboard, P2–P4 appear when gamepads are present.
- Hunter HP, invulnerability window, downed state, team wipe, mission failure, retry.
- Cooperative revive interaction.
- Two Recovery Pulse tactical consumables per hunter; proximity heal.
- Individual X Gauge generated by combat and strongly rewarded by handoffs.
- First playable Install layer:
  - Riven — Arsenal Overflow
  - Vale — Fracture State
  - Knox — Heavy Manifest
  - Morrow — Full Network
- Shared passive selection persisted in local save:
  - Relay Capacitor
  - Break Amplifier
  - Recovery Mesh
- First functional witch combat roles:
  - Hex — projectile pressure
  - Coven — nearby formation support / Break recovery
  - Ritual — interruptible team-damage cast
  - Siren — forced-position pull
  - Magical — boss/rival class
- HUD now exposes HP, X Gauge, tactical charges, inactive seats, and downed state.
- Results now score survival/support statistics alongside handoffs and chains.

## Controls
P1: WASD / J Light / K Heavy / L Signature / Q Defense / Space Evade / R Install / F Recovery Pulse / E Revive / Esc Pause

P2–4: Gamepad LS / A Light / X Heavy / Y Signature / LB Defense / B Evade / RT Install / D-pad Up Recovery Pulse / RB Revive / Start Pause

## Still intentionally provisional
Final models, animations, VFX, audio, equipment names, narrative delivery, final world art, and exact balance values.
